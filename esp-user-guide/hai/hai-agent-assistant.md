# What is HAi Agent Assistant?

HAi Agent Assistant is an AI-powered support capability designed to help service desk analysts and support teams work more efficiently within Hornbill. It provides contextual assistance during request handling, helping agents find information faster, make better decisions, and reduce the time taken to resolve issues.

## Purpose

The purpose of HAi Agent Assistant is to support analysts during the lifecycle of a request by:

- surfacing relevant information quickly
- reducing manual effort
- improving consistency in responses and actions
- helping agents resolve requests more efficiently

Rather than replacing the analyst, HAi Agent Assistant acts as a co-pilot that supports day-to-day service management tasks.

## What HAi Agent Assistant can do

Depending on how it is configured and used, HAi Agent Assistant can help with tasks such as:

- summarizing requests and conversations
- suggesting next steps for request handling
- identifying useful knowledge or documentation
- assisting with categorization or triage
- helping analysts understand related context more quickly
- drafting helpful responses or internal notes

This allows support teams to spend less time searching and more time resolving.

## Benefits

Using HAi Agent Assistant can provide a number of benefits, including:

- faster response and resolution times
- improved analyst productivity
- more consistent support outcomes
- quicker access to relevant knowledge
- reduced effort on repetitive administrative tasks
- better support for new or less experienced analysts

## How it supports analysts

HAi Agent Assistant is intended to work alongside support teams by enhancing human decision-making. Analysts remain in control of the work, while the assistant provides guidance, suggestions, and drafted content that can be reviewed and used where appropriate.

This approach helps maintain service quality while making support processes more efficient.

## Typical use cases

Examples of where HAi Agent Assistant may be useful include:

- reviewing a request and producing a short summary
- helping identify the likely service, category, or next action
- retrieving relevant knowledge to support resolution
- drafting customer-friendly updates
- assisting agents with repetitive support processes

## Summary

HAi Agent Assistant is an intelligent support tool for service management teams. It helps analysts work faster and more effectively by providing context-aware assistance within Hornbill, improving both operational efficiency and the overall support experience.
